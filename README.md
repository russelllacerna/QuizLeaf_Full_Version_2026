# QuizLeaf Full Version 2026

This is a separate, self-contained QuizLeaf React/Vite project. It does not overwrite your existing QuizLeaf project.

## Run

1. Open this folder in VS Code.
2. Open the terminal in this folder.
3. Run:
   npm install
   npm run dev
4. Open the localhost URL shown by Vite.

## Included

- Leaf-shaped interactive flashcards
- Flip question/answer
- Previous/Next
- Again / Got it review buttons
- Create, edit, delete decks
- Search decks
- LocalStorage persistence
- Responsive design
- Starter decks
- No backend required

## Important

This version stores data in the browser's localStorage. It is fully functional for a local/demo project, but it does not yet have accounts or a database.
